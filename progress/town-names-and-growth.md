# 町名と町の成長

## Decision

町に名前を付け、鉄道が来ている町だけが育つようにした(v0.3.0-Alpha-5)。

- **町名**は「前部(青・東・新…)＋中部(野・川・橋…)＋接尾(町・市・村)」の組み合わせで
  生成する。`generateTowns` と同じ rng の系譜から引くので、同じシードなら配置も名前も同じ。
  重複はその場で引き直す。
- **成長は月次**。`stepWorld` が月末に `townGrowth` イベントを出し、React 側が
  towns state を差し替える。sim 側も `world.towns` を同時に差し替えるので、
  次の tick の `demandFactor` にはすぐ効く。
- **成長率は鉄道アクセスの良さ(`townServiceLevel`, 0〜1)に比例**する。
  アクセス = 「町の半径10タイル以内にあり、かつ実際に列車が停まる駅」からの近さの合計。
  最良で月+3%、鉄道が来ていない町は横ばい。人口上限は50,000人。
- 育った町は `demandFactor` が上がるので、そのまま旅客需要に効く。
  「線路を引く → 町が育つ → 客が増える」というループになる。

## Alternatives considered
- **輸送実績(月間の乗降人数)で成長させる**: より正確だが、路線を作った直後の
  「まだ客がいないから育たない、育たないから客が増えない」という鶏卵状態になりやすい。
  駅があって列車が停まること自体を成長の条件にした。
- **鉄道が無い町を衰退させる**: 序盤に手が回らない町が勝手に消えるのは理不尽なので、
  横ばいに留めた。
- **町名をユーザーが編集できるようにする**: 今回は入れていない。駅名の改名UIと
  合わせて検討するのが自然。

## 追記(駅名の町名採用と、駅の建設で町が湧く仕組み)

- **駅名は近くの町の名前から採る**。`nearestTownWithinRadius`(towns.ts)で駅から
  `TOWN_STATION_RADIUS`以内の最も近い町を探し、あれば`stationNameForTown`で
  町名(末尾の「町」「市」「村」を除去)＋「駅」を付ける。近くに町が無ければ従来の
  A駅/B駅方式(`nextStationName`)にフォールバックする。
- **同じ町に2つ目以降の駅を建てたときの被り対策**はTTD流に、以下の順で
  未使用の名前を探す: ① 町名そのまま → ② 方角つき(町の中心から見た駅の方角、
  東西南北のうち最も強い1方向だけを使う。東西と南北が拮抗する場合は東西を優先) →
  ③「〜中央」→ ④「新〜」→ ⑤「〜台/森/谷/浜/橋」(この順) → ⑥ それでも埋まって
  いれば「〜第N」で必ず一意な名前になるまで番号を進める。
- **何も無い所に駅を作ると町が湧くことがある**。`maybeSpawnTownForStation`が、
  駅の`TOWN_STATION_RADIUS`以内に町が1つも無いときだけ`NEW_TOWN_CHANCE`(=0.5)の
  確率で駅から1〜3タイル離れた平地(`terrainAt`で水域・山岳を除外)に小さな町
  (`NEW_TOWN_POPULATION_MIN`〜`MAX`=100〜400人)を生成する。既存の町名生成
  (`nextTownName`)を再利用するので既存の町名とは重複しない。
- **呼び出し順序**: `useGameLogic.ts`の`commitPath`のstation分岐で、
  ①`maybeSpawnTownForStation`で町を決める → ②(湧いていれば)その町を足した
  towns配列を`applyStation`に渡して駅名を決める → ③ 建設が成立した(no-opで
  ない)ときだけ`setTowns`で新しい町をReact stateに反映する、という順を守る。
  一度付いた駅名は町が後から育っても変わらない(駅名の再計算はしない)。
- ブラウザ実機で確認: 町の近くに駅を建てると町名由来の駅名(「古台駅」)になり、
  同じ町に2つ目を建てると方角つきの名前(「南古台駅」)になる。町から離れた
  場所に建てると従来のA駅/B駅方式にフォールバックする。

## Constraints / Gotchas
- `TownData.name` は必須フィールドにした。v11 以前のセーブには無いため、
  `fallbackTownName(index)` で決定的な名前を補って移行する。
- 町の成長は sim 層が `world.towns` を**差し替える**(配列も要素も新しくする)。
  React の towns state と同一参照ではなくなるので、`townGrowth` イベントを
  受けて `setTowns` すること。受け損ねると画面の人口表示だけ古いままになる。
- `townServiceLevel` は「列車が停まる駅」の集合をサービス網(`buildServiceGraph`)の
  キーから取っている。運行表に載っていない駅は、線路が繋がっていても数に入らない。
