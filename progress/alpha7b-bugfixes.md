# Alpha-7b: 5件の不具合修正

v0.1.0-Alpha-7b で対応した5件の不具合と設計判断をまとめる。

## 1. 乗客数に小数が混在する (sim)

`waiting`(駅の待ち人数)は `PASSENGER_SPAWN_RATE × demandFactor × dt` で毎tick小数
のまま増加する。従来の乗車処理は `Math.min(waitingCount, TRAIN_CAPACITY)` をそのまま
`rt.passengers` に代入していたため、waitingが小数のときpassengersにも端数が乗ってし
まっていた。

`stepTrain` の乗車処理を「乗車人数は `Math.floor(waiting)` と
`TRAIN_CAPACITY - 現乗客` の小さい方」に修正し、端数はwaitingに残すようにした
(`src/sim/simulation.ts`)。UI側(`StationLabel.tsx`, `GameUI.tsx`)は元々waiting表示に
`Math.floor` を使っており修正不要だった。

## 2. 線路描画のリワーク (描画)

従来の `RailBlock.tsx` は直線ペア/斜めペア/カーブ/ハーフレールを個別に組み合わせる
方式で、接続の組み合わせによっては境界点が隣接セルの描画と厳密に一致せず、カーブの
境目で線路が途切れる箇所があった。

各接続方向ビットについて「セル中心→その方向の辺(カーディナル)または角(斜め)の中点
(隣接セルとの境界点)」までレールを2本(進行方向に垂直に±0.15オフセット)描く方式に
作り直した。境界点は隣接セル側の描画と座標として厳密に一致するため、直線・カーブ・
分岐などどんな組み合わせでも途切れない。中心では各方向のセグメントが重なり小さな
継ぎ目が出るため、短い縦円柱を中心に置いて隠している。

ブラウザで直線・45度カーブ・直角の折れ・3方向以上の分岐を実際に敷き、スクリーン
ショットで途切れがないことを確認した。

## 3. 停車時に線路の向きを無視して停まる (sim + 描画)

`DynamicTrain` は `runtime.renderTarget` へ `lookAt` することで列車の向きを描画してい
るが、駅到着(停車)処理では `renderPos` をセル中心にスナップするだけで `renderTarget`
を更新していなかった。その結果、停車の瞬間に `lookAt` が働かなくなり、列車の向きが
初期値にリセットされているように見えていた。

停車処理(`stepTrain` の `shouldStop` 分岐)で、進入方向(直前セル→到着セル)の延長線上
の点を `renderTarget` に設定し、発車まで向きを維持するようにした
(`src/sim/simulation.ts`)。人身事故による `haltRemaining` 中も同じ tick で設定された
`renderTarget` がそのまま維持されるため、追加対応は不要。

TDDでテストを先に追加(停車直後に `renderTarget` が進入方向を指すこと)し、Red→Green
を確認した。

## 4. 無信号の複線で右側通行になる (sim)

`pathfinding.ts` のBFSは隣接方向の列挙順が固定(N,NE,E,...)だったため、同距離の並行
経路(交換設備や複線)のタイブレークが常に同じ側に倒れ、対向列車が「右側通行」を選ん
でしまっていた。日本式の左側通行をデフォルトにしたい。

進行方向ベクトル `dv`(現在セル-直前セル)と候補方向 `d` の符号付き外積
`dv.x*d.z - dv.z*d.x` を「進行方向左側への寄り具合」の指標とし、この値が大きい候補
から順にBFSキューへ積むよう `validMoves` をソートした。BFSはFIFOのため、同距離なら
先に積んだ左寄りの経路が採用される。座標系は x+=東, z+=南で、この座標系・カメラ視点
において東行きはz+側(南)、西行きはz-側(北)の並行線を選ぶことをテストで固定した(テ
ストのコメントに定義を明記)。

既存の `passing-loop.test.ts`(信号場での自動すれ違い、頑健性テスト)は本修正後も
そのままパスすることを確認済み。

## 5. 信号の向きがわかりづらい (描画)

従来の `SignalBlock.tsx` は支柱と灯器(緑/赤の小さな円柱)のみで、遠目には許可方向が
分かりにくかった。許可方向を示す平たい矢印(chevron、軸+く字形の矢羽根)を線路脇に
大きく描画するよう刷新した。回転は `RailBlock.tsx` と同じ規約
(`atan2(v.x, v.z)` で方向ベクトルに合わせてY軸回転する)に揃えている。

ブラウザで信号を設置し、`signalDir` を切り替えて(NE→SW)矢印の向きが追従することを
確認した。
