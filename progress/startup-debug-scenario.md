# 起動時デバッグシナリオと車輪の坂追従

## 決定

- 起動時に通常開始とデバッグモードを選べる画面を表示する。デバッグモードはセーブデータを読み書きせず、地平・坂・高架・両端駅・往復する2編成をその場で生成する。
- 坂で車体を傾けるときは、車両groupの原点をレール面の真上へ置くのではなく、レール面から台車までの高さを車体のローカル上方向に補正する。これにより傾斜時も車輪面がレールへ追従する。

## 制約 / 注意点

- デバッグシナリオはUI状態とruntimeを初期化するが、所持金などの経済表示値は通常開始と同じ初期値のままにする。目的は走行描画の確認であり、ゲーム開始条件の変更ではない。

## 追記 (v0.3.0-Alpha-24a)

- 初期のデバッグ列車を駅セルの中心に置いていたため、3両編成の後続車が初期履歴のないまま駅舎へ食い込んでいた。両編成を駅外の直線(-5/5)へ移動し、駅施設と編成長ぶんの空きがあることをテストで固定した。

## 追記 (v0.3.0-Alpha-25a)

- 交換設備・信号のない単線に対向2編成を置くと、描画確認用であっても運行として成立せず、予約待ちや衝突したような状態を招く。デバッグシナリオは安全な単編成の往復運行へ戻した。複数編成の確認は、将来専用の交換設備・信号を含むシナリオとして別に用意する。
