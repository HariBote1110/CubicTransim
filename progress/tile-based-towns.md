# タイルベースの町(家・道路)と建設ガード

## 背景

これまで町(town)は `TownBlocks.tsx` が中心座標の周りに極座標の連続値で建物メッシュを
散らすだけの装飾で、タイルグリッドを無視していた。また建設側は町を一切参照せず、
町のど真ん中に地平の線路や駅を敷けてしまっていた。これを OpenTTD 風の
「タイル単位の家・道路」に置き換え、建設ルールと結びつけた。

## 設計

### 決定的再生成(セーブ不要)

町タイルは **セーブデータに保存しない**。`src/sim/townTiles.ts` の純粋関数が、
町の id(文字列ハッシュ→シード)・人口・地形(terrain/heights)・線路網(railMap)から
毎回同じ配置を再生成する。persistence の変更・セーブ移行が不要になり、
人口が増えると自動的に半径と家の数が増えて「町が育つ」見た目になる。

- `townTileRadius(population)` = `min(7, 2 + floor(sqrt(pop/800)))`(チェビシェフ半径)
- `townHouseTarget(population)` = `max(5, round(pop/300))`

### レイアウトアルゴリズム(generateTownTiles)

1. **道路**: 町の中心を原点とする3タイル間隔の格子
   (`dx % 3 === 0 || dz % 3 === 0`、半径内)。中心から4近傍BFSで辿れるタイル
   だけを採用する(水域などで分断された飛び地の道路は作らない)。
2. **家**: 採用済み道路タイルに4近傍で隣接する平地から、
   「中心からの距離 + セルハッシュによるジッター(<0.9)」の昇順に人口ぶん選ぶ。
   逐次消費する rng ではなく (シード,x,z) のハッシュを使うため走査順に依存せず、
   人口が増えても既存の家の位置は保たれて外側へ広がるだけになる。
3. **除外**: `terrainAt !== 'grass'`、標高 `heights > 0`、他の町のタイル
   (`buildTownTileIndex` が towns 配列順の先勝ちで管理)。
4. **線路との関係**(重要な設計判断):
   - **家**は「地面を占有するセル」(`cellOccupiesGround`: 地平 connections を持つ、
     station/depot、ramp)を避ける。純粋な高架専用セル(uppers のみ)は避けない
     =高架は町の上を通過できる。
   - **道路**は素の線路セル(type 'rail'、坂を除く)との同居を許す=**踏切**。
     駅・車庫・坂セルには道路も作らない。あとから線路を道路タイルへ敷いても
     (下記ガードが許可する)道路網は変わらないので、町の見た目が安定する。

`buildTownTileIndex(towns, terrain, heights, railMap?)` が全町を合成した
`Map<セルキー, {townId, kind}>` を返す。`useGameLogic` が
`useMemo([towns, terrain, heights, railMap])` で保持し(91x91・十数町なので
建設のたびの再計算で十分軽い)、建設・プレビュー・描画のすべてに同じ索引を渡す。

### 建設ガード(construction.ts、すべて省略可能な引数で後方互換)

| 操作 | 家タイル | 道路タイル |
|---|---|---|
| 地平の線路(applyRailPathDetailed/applyRailPath) | **不可**(経路に1セルでもあれば全体no-op) | 可(踏切になる) |
| 高架の桁(applyElevatedPath の span) | 可(上空通過) | 可 |
| 高架の坂(ramp。地面に接する) | **不可** | 可 |
| 駅(applyStation)・車庫(applyDepot) | 不可 | 不可(道路網を寸断させない) |
| 信号(applySignal) | 不可 | 不可(踏切セルに信号機は建てない) |

no-op は従来の規約どおり**同一参照**を返すので、`buildPreview.evaluateBuild` は
townTiles を apply 系へ渡すだけで 'no-effect' を正しく表示する(UI に条件を書き写さない)。

### 新しい町の湧き(towns.ts)

`resolveTownSpawnTick`/`spawnTownNear` に省略可能な railMap を追加し、
地面を占有する線路セルの上には町の**中心**を置かない(中心は道路タイルになるため)。
simulation.ts は `world.railMap` を渡す。家は生成時に線路セルを避けるので、
中心さえ空いていれば湧いた町が既存線路と重なることはない。

### 描画

- `TownBlocks.tsx`: 全面書き換え。タイル索引を走査し、家=セル中央のボックス
  (大きさ・高さ・色は `hash01(x,z,salt)` で決定的に散らす。人口4000以上の町は
  18%の確率で高層ビル+パラペット、低層は寄棟屋根のコーン)、道路=縁石スラブ+
  アスファルトスラブ。マテリアルごとに `mergeAndDispose` でマージ(7ドローコール)、
  raycast 無効。町名ラベル(Html)は従来どおり中心に出す。
- 踏切: 線路が道路タイルを横切っても路面スラブを描いたままにするので、
  自然に「線路が路面を横切る」見た目になる。
- `Scenery.tsx`: 町中心からの円距離(TOWN_CLEARANCE=3.5)ではなく
  「町タイルとその周囲1タイル」に樹木を置かない方式へ変更。
- パレット: `roadAsphalt`/`roadKerb`/`buildingRoofFlat` と町用の共有マテリアルを
  `render/palette.ts` に追加。

## 未実装・今後の課題

- **踏切の遮断機・警報機の描画**(白赤の柵ポスト等)。データは不要
  (railMap の地平線路 × townTiles の道路タイルの共通セルで判定できる)。
- 列車が踏切を通過するときの演出(音・遮断機の開閉)。
- 家タイルの撤去(ブルドーザー)や、町の成長で家が線路予定地を塞いだときの
  買収コストのような経済的インタラクション。
- 道路を伝う自動車などの動く装飾。
