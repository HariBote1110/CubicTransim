# Canonical terrain noise: integer fixed-point definition

Status: release-authoritative prototype definition. Existing terrain seed compatibility is intentionally not preserved. The renderer and the future main TS implementation MUST implement this same integer algorithm.

## Domain

- Coordinates: signed i32 cell/corner coordinates.
- Lattice hash: u32 wrapping arithmetic.
- Octaves: `(wave, weight) = (40,8), (20,4), (10,2), (5,1)`.
- Each octave value is Q0.32: `q = round_half_up(value * 2^32)`, represented as u32.
- Composite numerator is `N = 8*q0 + 4*q1 + 2*q2 + q3`, represented as unsigned 64-bit.
- Canonical normalized noise is `N / (15 * 2^32)`. No floating-point operation is part of the definition.

## Pseudocode

```text
U64 = { hi:u32, lo:u32 } with modulo-2^64 add and exact u32×u32 multiplication.

hash(seed,x,z):
    h = seed XOR (u32(x) * 374761393) XOR (u32(z) * 668265263)
    h = (h XOR (h >> 13)) * 1274126177
    return h XOR (h >> 16)

deriveSeed(seed,i):
    h = seed XOR ((i+1) * 0x9e3779b9)
    h = (h XOR (h >> 15)) * 0x85ebca6b
    h = h XOR (h >> 13)
    h = h * 0xc2b2ae35
    return h XOR (h >> 16)

smoothQ(x,wave):
    grid = floor_euclidean(x / wave)
    r = x - grid * wave                 # 0 <= r < wave
    n = r*r*(3*wave - 2*r)
    d = wave^3
    return round_half_up(n * 2^32 / d)   # u32

lerpQ(a,b,t):
    if b >= a: return a + floor((b-a)*t / 2^32)
    else:      return a - floor((a-b)*t / 2^32)

valueNoise(seed,x,z,wave):
    (gx,tx) = smoothQ(x,wave)
    (gz,tz) = smoothQ(z,wave)
    v00 = hash( seed,gx,   gz   )
    v10 = hash( seed,gx+1, gz   )
    v01 = hash( seed,gx,   gz+1 )
    v11 = hash( seed,gx+1, gz+1 )
    top = lerpQ(v00,v10,tx)
    bottom = lerpQ(v01,v11,tx)
    return lerpQ(top,bottom,tz)

composite(seed,x,z):
    q0 = valueNoise(deriveSeed(seed,0),x,z,40)
    q1 = valueNoise(deriveSeed(seed,1),x,z,20)
    q2 = valueNoise(deriveSeed(seed,2),x,z,10)
    q3 = valueNoise(deriveSeed(seed,3),x,z,5)
    return 8*q0 + 4*q1 + 2*q2 + q3

water iff N < 9 * 2^30

height thresholds (N is integer):
    h=0 below 35,433,480,192
    h=1 at/above 35,433,480,192
    h=2 at/above 41,290,253,778
    h=3 at/above 47,147,027,363
    h=4 at/above 53,003,800,949
    h=5 at/above 58,860,574,534
    h=6 at/above 64,717,348,120
    h=7 at/above 70,574,121,705
    h=8 at/above 76,430,895,291
    h=9 at/above 82,287,668,876
    h=10 at/above 88,144,442,462

Out-of-range corners are height 0 and not water.
```

## Why this is canonical

The smoothstep polynomial is evaluated from the exact rational `r^2(3w-2r)/w^3`, then quantized once to Q0.32. Interpolation uses exact 64-bit products and truncation toward zero after division by `2^32`. Octave weighting and normalization are kept as one integer numerator, so there is no f32/f64 boundary behavior left to reproduce.

## Verification

WGSL vs the Rust canonical implementation: 5 seeds × 10,000,000 points = 50,000,000 points, 0 mismatches on the VM's Vulkan/llvmpipe backend. Seeds: `0x00000000`, `0x00000001`, `0x12345678`, `0xDEADBEEF`, `0xFFFFFFFF`.
